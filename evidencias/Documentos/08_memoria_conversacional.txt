**1. Registro y clasificación de la solicitud**
El proceso inicia cuando el cliente presenta su inconformidad a través de un canal autorizado. Para que el caso pueda ser analizado, se requiere contar con la siguiente información mínima:
- Identificador del cliente.
- Producto relacionado (tarjeta, cuenta, etc.).
- Fecha aproximada de la operación.
- Monto del cargo.
- Canal donde se realizó el movimiento.
- Descripción clara de por qué no se reconoce el cargo.

Si falta alguno de estos datos, el caso queda **pendiente de complemento** hasta que el cliente proporcione la información faltante.

**2. Análisis operativo**
El analista clasifica el tipo de aclaración (cargo no reconocido) y verifica que no exista una solicitud duplicada sobre la misma operación. Posteriormente, consulta los sistemas internos para validar:
- Si el movimiento existe en los registros.
- Si fue aplicado correctamente.
- Si existen reversos, comisiones asociadas, operaciones duplicadas o registros pendientes de conciliación.

**3. Determinación del resultado**
- **Si la evidencia confirma que el cargo fue aplicado correctamente**, el caso se documenta como **no procedente** y se comunica al cliente la explicación correspondiente.
- **Si se detecta una inconsistencia operativa** (por ejemplo, un error en el sistema, un cobro duplicado o un movimiento no autorizado), el analista registra la causa, solicita la corrección al área correspondiente y da seguimiento hasta confirmar el ajuste o la resolución del movimiento.

**4. Escalamiento (si aplica)**
Una aclaración debe escalarse cuando involucra:
- Posible fraude.
- Montos altos.
- Inconsistencias entre sistemas.
- Afectación a varios clientes.
- Falta de evidencia suficiente para resolver en primer nivel.

El escalamiento debe incluir el motivo, la evidencia revisada, los sistemas consultados y el área destino. No debe prometerse una resolución antes de recibir confirmación del área responsable.

**5. Cierre del caso**
El cierre puede clasificarse como:
- **Procedente** (se reconoce el error y se corrige).
- **No procedente** (el cargo es válido).
- **Pendiente de información** (faltan datos del cliente).
- **Escalado** (se deriva a otra área).

En todos los casos debe quedar evidencia del análisis realizado, el estado final, el motivo de la decisión y la acción correctiva cuando aplique. La respuesta final al cliente debe ser clara, verificable y limitada a la información confirmada durante la revisión.

**Importante:** Si los datos proporcionados por el cliente son insuficientes para ubicar la operación, el caso no debe cerrarse sin contar con los elementos mínimos para revisar el movimiento cuestionado.
